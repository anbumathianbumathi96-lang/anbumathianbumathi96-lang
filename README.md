### 🚀 Featured Project

#### 🛰️ TinyML-Based Inertial Navigation System
**Real-Time Drift Estimation and Correction Using STM32F407**

An embedded intelligence project combining an STM32F407 microcontroller, MPU9250 IMU, sensor processing and TinyML.

**Core Technologies**

![STM32F407](https://img.shields.io/badge/-STM32F407-03234B?style=flat-square&logo=stmicroelectronics&logoColor=white)
![C](https://img.shields.io/badge/-C-00599C?style=flat-square&logo=c&logoColor=white)
![MPU9250](https://img.shields.io/badge/-MPU9250-informational?style=flat-square)
![TinyML](https://img.shields.io/badge/-TinyML-informational?style=flat-square)
![Edge Impulse](https://img.shields.io/badge/-Edge_Impulse-informational?style=flat-square)
![IMU](https://img.shields.io/badge/-IMU-informational?style=flat-square)
![Sensor Fusion](https://img.shields.io/badge/-Sensor_Fusion-informational?style=flat-square)
![Embedded C](https://img.shields.io/badge/-Embedded_C-informational?style=flat-square)

**Project Goals**

- 📡 Collect real-time IMU data
- ⚙️ Process accelerometer and gyroscope signals
- 🧮 Implement sensor filtering
- 🧠 Use TinyML for drift/bias estimation
- ⚡ Perform inference directly on the microcontroller
- 💾 Log sensor data
- 🚀 Explore intelligent inertial navigation systems

> **Goal:** Move beyond traditional filtering by using machine learning to identify and compensate for sensor drift on an embedded device.
